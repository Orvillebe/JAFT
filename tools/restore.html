JAFT restore

Turns a backup file (exported in Instellingen) into an SQL script that puts the data back into the database. The file stays in this browser; nothing is sent anywhere.

Before you run the script: the database must be at the version this code expects (run the migrations first) and must hold no contacts, companies or week actions yet. The script checks both and stops otherwise. Users aren't restored: create them in Supabase and set allowed to true in members.

Then: Supabase › SQL Editor › New query › paste › Run. The check at the end should show the same counts as the first lines of the script.
